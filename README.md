# Agentic-Protocol-Quantum-Readiness-Scanner
A hardening framework that assesses post-quantum cryptographic readiness across the five leading agent communication protocols: MCP, A2A, ACP, ANP, and AITP.

Inspired by Dr. Tehrani's warning that current agent protocols fall into one of two failure modes — False Quantum Safety or Blind Legacy Dependencies — this project turns the critique into a practical, hands-on tool. It inspects protocol traffic, discovers cryptographic assets, scores quantum readiness, and demonstrates mitigation paths using NIST-standardized PQC primitives (ML-KEM, ML-DSA, SLH-DSA).

The goal is educational and operational: help engineers see why a 100% score can be the bigger lie, and how to migrate toward genuine crypto-agility before the cryptographic ticking bomb detonates.
